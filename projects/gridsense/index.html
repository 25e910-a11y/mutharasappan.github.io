GridSense

A system that watches a 3-phase supply panel by panel and tells maintenance staff which panel and which phase has a problem, before someone has to go looking for it.

  • Prototype in progress
  • Vishwakarma Awards 2026-27, Stage 3
  • Sustainable Energy: Smart Grids & Decentralised Power Distribution
  • PSG College of Technology, Coimbatore

The problem

In a campus, hospital or factory, an electrical problem usually gets found when something visibly stops working. The meters that are installed report how much energy was used. They don't say which panel or which phase started drifting, or when. So someone walks from board to board looking for it.

Electrical faults are a steady cause of fires in India. Short circuit was given as the cause of 1,567 of the 7,566 fires recorded in 2022, and of 1,780 fires in 2023 (source: NCRB, Accidental Deaths & Suicides in India, 2022 and 2023). Finding a problem early matters.

What GridSense does

Each panel gets a small node that reads voltage, current, power, energy, frequency and power factor on all three phases, plus the enclosure temperature. The node sends every reading to a backend, which checks it and says exactly where the problem is:

  1. Campus
  2. Block
  3. Floor
  4. Panel
  5. Phase R / Y / B

Every event is logged with the panel, phase, value and time. Maintenance is alerted, a work order is assigned, and the work order closes only after a new reading from that phase is back to normal.

Alarm rules

CheckDefault limit
UndervoltageBelow 195.5 V (15% under 230 V)
OvervoltageAbove 253 V (10% over 230 V)
Phase imbalanceAbove 10%
Loss of voltage15 V or less, and only when another phase still has healthy voltage
Enclosure temperature65 °C, warning only
Device offlineNo reading for 120 s

A meter module that stops answering is logged as a sensor fault, never as a lost phase. Limits can be changed per device, and a new device can run in log-only mode while its limits are checked against a reference meter.

Software

The backend is written in Python with FastAPI and PostgreSQL. The dashboard is React with TypeScript and shows live readings per phase, faults, work orders and the campus layout. A built-in simulator sends test readings, which are stored and shown as demo data. The code is on GitHub.

Where it stands

GridSense cleared Stage 1 and Stage 2 of the Vishwakarma Awards 2026-27. The backend, dashboard and database run on a laptop and the backend tests pass. Our team is now building the working hardware prototype for the Stage 3 submission in December 2026.

GridSense only monitors and alerts. It does not protect anything and does not replace fuses, MCBs, earthing or proper isolation. All mains work is done under qualified supervision.
